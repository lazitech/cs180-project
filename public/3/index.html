1.2 Classical Denoising

Dividing by \(t\) restores the image amplitude, but it amplifies the noise by the same factor. A Gaussian filter then trades noise for detail.

\[\frac{x_t}{t} = x_1 + \frac{1-t}{t}\,\epsilon\]\[\hat{x}_1^{\mathrm{blur}} = G_\sigma\!\left(\frac{x_t}{t}\right)\]

For each time I sweep \(\sigma \in \{1, 2, 4, 8, 16\}\) with kernel size \(6\sigma + 1\) and keep the result with the lowest mean squared error against my known clean image. The noise multiplier \((1-t)/t\) equals \(3,\ 1,\ \tfrac{1}{3}\) at the three times, and the selected \(\sigma\) falls \(8 \to 4 \to 2\) as the noise weakens.

1.3 One-Step Denoising

The model predicts a velocity: the direction from noise toward the image. Following it for the remaining time \(1 - t\) in a single step estimates the clean image. Each estimate uses exactly one model evaluation with the prompt "a high quality photo".

\[\hat{x}_1 = x_t + (1-t)\,v_\theta(x_t, t, c) \tag{A.2}\]

1.4 Visualizing Velocity

The predicted update \((1-t)\hat{v}_t\) is exactly what one-step denoising adds to \(x_t\). The ground-truth update \((1-t)(x_1 - \epsilon) = x_1 - x_t\) would recover my original image exactly.

\[\hat{v}_t = v_\theta(x_t, t, c), \qquad v_{\mathrm{gt}} = x_1 - \epsilon\]\[(1-t)\,v_{\mathrm{gt}} = x_1 - x_t\]\[E_t = \sqrt{\operatorname{mean}_{\mathrm{RGB}}\!\left(\big[(1-t)(\hat{v}_t - v_{\mathrm{gt}})\big]^2\right)}\]

velocity_diagnostics

@torch.inference_mode()
def velocity_diagnostics(x_t, t, clean_image, epsilon, condition, predict_velocity):
    """Return predicted_update, ground_truth_update, and error_map.

    Both updates have shape (B, 3, H, W).
    The error map has shape (B, H, W): average only over RGB, keeping each pixel.
    Return raw values before display scaling or clipping.
    """
    v_hat = predict_velocity(x_t, t, condition)
    v_gt = clean_image - epsilon  # path velocity x_1 - eps, so (1-t) v_gt = x_1 - x_t
    predicted_update = (1 - t) * v_hat
    ground_truth_update = (1 - t) * v_gt
    # Per-pixel RMS over RGB: square, mean over the channel axis, then sqrt.
    error_map = (predicted_update - ground_truth_update).square().mean(dim=1).sqrt()
    return predicted_update, ground_truth_update, error_map

Updates share one symmetric RGB scale, \(u \mapsto 0.5 + u/(2L)\), with \(L\) the largest \(|u|\) over all six update maps. Zero is middle gray.

Error maps use a linear viridis scale with vmin = 0 and vmax equal to the largest error over all three times, so the limits match across rows.

1.5 Iterative Denoising with Euler Sampling

Euler integration re-evaluates the velocity after every update. Starting from the saved \(t = 0.50\) input with \(h = 0.02\), the sampler takes 25 updates to reach \(t = 1\).

\[x_{t+h} = x_t + h\,v_\theta(x_t, t, c) \tag{A.3}\]\[n = \left\lceil \frac{1 - t_{\mathrm{start}}}{h} \right\rceil, \qquad h_{\mathrm{last}} = 1 - \big(t_{\mathrm{start}} + (n-1)\,h\big)\]

euler_sample

@torch.inference_mode()
def euler_sample(x_start, t_start, step_size, velocity, save_every=5):
    n_steps = max(0,math.ceil((1-t_start)/step_size-1e-6))
    x = x_start
    states = [(t_start,x)]
    for k in range(n_steps):
        t = t_start + k*step_size
        h = step_size if k < n_steps - 1 else 1 - t
        x = x + h*velocity(x, t)
        if k == n_steps - 1:
            states.append((1.0, x))
        elif (k + 1)%save_every == 0:
            states.append((t_start + (k + 1)*step_size, x))
    return x, states

Part 2: Conditional Generation and Guidance

2.1 Classifier-Free Guidance (CFG)

Classifier-free guidance evaluates the model twice at the same \(x_t\) and \(t\): once with the prompt and once with the empty string. Extrapolating past the conditional velocity strengthens the prompt.

\[v_{\mathrm{cfg}} = v_c + w\,(v_c - v_u) \tag{A.4}\]\[v_c = v_\theta(x_t, t, c), \qquad v_u = v_\theta(x_t, t, \varnothing), \qquad w = 7,\ h = 0.02\]

cfg_velocity

def cfg_velocity(x, t, condition, w, predict_velocity, null_condition=''):
    v_c = predict_velocity(x,t,condition)
    v_u = predict_velocity(x,t,null_condition)
    return v_c + w*(v_c-v_u)

Both branches see the same \(x_t\) and \(t\), and \(\varnothing\) denotes the empty-string prompt. With \(w = 0\) the guided velocity equals the conditional prediction. Each guided step costs two model evaluations, so a sample takes 100.

3.1 Image-to-Image Editing

SDEdit-style editing starts the sampler part-way along the path. A real image is mixed with noise at \(t_{\mathrm{start}}\), then integrated to \(t = 1\) with CFG and the prompt "a high quality photo". A smaller starting time adds more noise and leaves the model more freedom.

\[x_{t_{\mathrm{start}}} = (1 - t_{\mathrm{start}})\,\epsilon + t_{\mathrm{start}}\,x_1\]\[\hat{x}_1 = x_{t_{\mathrm{start}}} + \int_{t_{\mathrm{start}}}^{1} v_{\mathrm{cfg}}(x_t, t, c)\,dt \qquad (\text{Euler},\ h = 0.02,\ w = 7)\]

def edit(image, noise, t_start, condition, predict_velocity, w=7, step_size=0.02):
    x = interpolate(image,noise,t_start)
    x, _ = euler_sample(x,t_start,step_size,lambda x,t: cfg_velocity(x,t,condition,w,predict_velocity))

3.3 Visual Anagrams

At every Euler step I combine two guided velocities: prompt \(p_1\) on the upright image, and prompt \(p_2\) on the image rotated 180°, rotated back. The sample is pushed to satisfy both prompts, one in each orientation.

\[v_1 = \mathrm{CFG}(x_t, t, p_1)\]\[v_2 = F\big(\mathrm{CFG}(F(x_t), t, p_2)\big)\]\[v = \tfrac{1}{2}(v_1 + v_2), \qquad x_{t+h} = x_t + h\,v\]\[F:\ \text{rotation by } 180^\circ \text{ (flip of both spatial axes)}\]

visual_anagrams

def visual_anagrams(noise, condition_a, condition_b, predict_velocity, w=7, step_size=0.02):
    def velocity(x, t):
        v_a = cfg_velocity(x,t,condition_a,w,predict_velocity)
        v_b = rotate180(cfg_velocity(rotate180(x),t,condition_b,w,predict_velocity))
        return (v_a + v_b) / 2
    x, _ = euler_sample(noise,0,step_size,velocity)
    return x

3.4 Hybrid Images

Factorized diffusion splits the composite velocity by spatial frequency. The low-pass of one guided velocity sets what is visible from afar; the high-pass of the other sets the detail seen up close.

\[v_1 = \mathrm{CFG}(x_t, t, p_{\mathrm{distant}}), \qquad v_2 = \mathrm{CFG}(x_t, t, p_{\mathrm{close}})\]\[v = f_{\mathrm{lowpass}}(v_1) + f_{\mathrm{highpass}}(v_2) = G_{16}(v_1) + \big(v_2 - G_{16}(v_2)\big)\]\[G_{16}:\ \text{Gaussian blur, kernel size } 265,\ \sigma = 16 \text{ at } 512 \times 512\]

make_hybrids

def make_hybrids(noise, condition_a, condition_b, predict_velocity, w=7, step_size=0.02):
    def velocity(x, t):
        v_a = cfg_velocity(x, t, condition_a, w, predict_velocity)
        v_b = cfg_velocity(x, t, condition_b, w, predict_velocity)
        return lowpass(v_a) + v_b - lowpass(v_b)

    x, _ = euler_sample(noise, 0, step_size, velocity)
    return x

Part 1: Training a Single-Step Denoising UNet

1.1 Implementing the UNet

The denoiser is a UNet with hidden width \(D\). Two DownBlocks take the \(28 \times 28\) input to \(7 \times 7\), Flatten averages each \(7 \times 7\) channel to a single value, and Unflatten and two UpBlocks return to full resolution. At every resolution the encoder features are concatenated with the decoder features.

OperationLayersShape
ConvConv2d(3, 1, 1) + BN + GELU\((D_{\mathrm{in}}, H, W) \to (D_{\mathrm{out}}, H, W)\)
DownConvConv2d(3, 2, 1) + BN + GELU\(\to (D_{\mathrm{out}}, H/2, W/2)\)
UpConvConvTranspose2d(4, 2, 1) + BN + GELU\(\to (D_{\mathrm{out}}, 2H, 2W)\)
FlattenAvgPool2d(7) + GELU\((D, 7, 7) \to (D, 1, 1)\)
UnflattenConvTranspose2d(7, 7, 0) + BN + GELU\((D, 1, 1) \to (D, 7, 7)\)
ConvBlockConv, then Convresolution kept
DownBlockDownConv, then ConvBlockresolution halved
UpBlockUpConv, then ConvBlockresolution doubled

UnconditionalUNet

class UnconditionalUNet(nn.Module):
    def __init__(
        self,
        in_channels: int,
        num_hiddens: int,
    ):
        super().__init__()
        D = num_hiddens
        self.conv1 = ConvBlock(in_channels, D)
        self.down1 = DownBlock(D, D)
        self.down2 = DownBlock(D, 2*D)
        self.flatten = Flatten()
        self.unflatten = Unflatten(2*D)
        self.up1 = UpBlock(4*D, D)
        self.up2 = UpBlock(2*D, D)
        self.conv2 = ConvBlock(2*D, D)
        self.conv3 = nn.Conv2d(D, in_channels, kernel_size=3, stride=1, padding=1)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        assert x.shape[-2:] == (28, 28), "Expect input shape to be (28, 28)."
        x1 = self.conv1(x)
        x2 = self.down1(x1)
        x3 = self.down2(x2)

        y0 = self.unflatten(self.flatten(x3))
        y1 = self.up1(torch.cat([x3, y0], dim=1))
        y2 = self.up2(torch.cat([x2, y1], dim=1))
        y3 = self.conv2(torch.cat([x1, y2], dim=1))
        return self.conv3(y3)

1.2.3 Denoising Pure Noise

To use the denoiser as a generator, its input becomes pure noise \(\epsilon \sim \mathcal{N}(0, I)\) with no trace of the digit, while the target is still a clean training digit. Architecture and schedule match Section 1.2.1.

\[L = \mathbb{E}_{\epsilon, x}\,\lVert D_\theta(\epsilon) - x \rVert^2\]

Fresh noise inputs after epoch 1

Input \(\epsilon\)pure noise

Output\(D_\theta(\epsilon)\)

Fresh noise inputs after epoch 5

Input \(\epsilon\)pure noise

Output\(D_\theta(\epsilon)\)

Pattern

Every output is the same blurry, digit-shaped blob, closest to an 8 drawn over a 0 and a 3. It does not depend on the input noise, it already looks this way after epoch 1, and epoch 5 changes almost nothing. It matches the mean of the training images.

Why

Under an MSE loss, the best prediction for an input \(z\) is \(\mathbb{E}[x \mid z]\). Because \(\epsilon\) is independent of \(x\), the input carries no information and \(\mathbb{E}[x \mid \epsilon] = \mathbb{E}[x]\): the network learns to ignore its input and output the centroid of the training set. The loss plateaus near 0.07 after about 50 steps, which is the per-pixel variance of the digits around their mean, the floor for any prediction that ignores the input. One-step denoising of pure noise therefore cannot generate new digits.

Part 2: Training a Flow Matching Model

2.1 Time Conditioning

Flow matching turns generation into many small steps. A noisy sample \(x_t\) lies on the straight line from Gaussian noise \(x_0\) at \(t = 0\) to a clean digit \(x_1\) at \(t = 1\), and the UNet learns the velocity along that line.

\[x_t = (1-t)\,x_0 + t\,x_1, \qquad x_0 \sim \mathcal{N}(0, I),\ t \in [0, 1] \tag{B.3}\]\[u(x_t, t) = \frac{d}{dt}\,x_t = x_1 - x_0 \tag{B.4}\]\[L = \mathbb{E}_{x_0, x_1, t}\,\lVert (x_1 - x_0) - u_\theta(x_t, t) \rVert^2 \tag{B.5}\]

The scalar \(t \in [0, 1]\) enters through two FCBlocks, each Linear, GELU, Linear. fc1 maps \(t\) to \(2D\) values that scale the Unflatten output \((2D \times 7 \times 7)\); fc2 maps it to \(D\) values that scale the first UpBlock output \((D \times 14 \times 14)\). Each embedding is reshaped to \((N, C, 1, 1)\) and broadcast over all spatial positions. Since \(t\) is drawn from \([0, 1]\), it is already normalized.

FCBlock

class FCBlock(nn.Module):
    def __init__(self, in_channels: int, out_channels: int):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(in_channels,out_channels),
            nn.GELU(),
            nn.Linear(out_channels,out_channels)
        )

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        return self.net(x)

TimeConditionalUNet.forward

def forward(
    self,
    x: torch.Tensor,
    t: torch.Tensor,
) -> torch.Tensor:
    assert x.shape[-2:] == (28, 28), "Expect input shape to be (28, 28)."
    t = t.float()
    x1 = self.conv1(x)
    x2 = self.down1(x1)
    x3 = self.down2(x2)

    t1 = self.fc1(t[:, None])[:,:,None,None]
    t2 = self.fc2(t[:, None])[:,:,None,None]

    y0 = self.unflatten(self.flatten(x3))*t1
    y1 = self.up1(torch.cat([x3, y0], dim=1))*t2
    y2 = self.up2(torch.cat([x2, y1], dim=1))
    y3 = self.conv2(torch.cat([x1, y2], dim=1))
    return self.conv3(y3)

2.2 Training the Time-Conditioned UNet

Each step takes a batch of clean digits \(x_1\), draws an independent \(t \sim U[0, 1]\) and noise \(x_0\) for every image, forms \(x_t\), and regresses the velocity \(x_1 - x_0\) (Algorithm B.1).

time_fm_forward

def time_fm_forward(
    unet: TimeConditionalUNet,
    x_1: torch.Tensor,
    num_ts: int,
) -> torch.Tensor:
    unet.train()
    N = x_1.shape[0]
    t = torch.rand(N, device=x_1.device)
    x_0 = torch.randn_like(x_1)
    t_b = t[:, None, None, None]
    x_t = (1 - t_b) * x_0 + t_b * x_1
    return F.mse_loss(unet(x_t, t), x_1 - x_0)

2.3 Sampling from the Time-Conditioned UNet

\[x \leftarrow x + \tfrac{1}{T}\,u_\theta(x, t), \qquad t = 0, \tfrac{1}{T}, \ldots, \tfrac{T-1}{T}\]

time_fm_sample

@torch.inference_mode()
def time_fm_sample(
    unet: TimeConditionalUNet,
    img_wh: tuple[int, int],
    num_ts: int,
    seed: int = 0,
    N: int = 40
) -> torch.Tensor:
    unet.eval()
    device = next(unet.parameters()).device
    g = torch.Generator().manual_seed(seed)
    x = torch.randn(N, 1, *img_wh, generator=g).to(device)
    for i in range(num_ts):
        t = torch.full((N,), i / num_ts, device=device)
        x = x + unet(x, t) / num_ts
    return x

Part 2: Training a Flow Matching Model

2.4 Class Conditioning

To control which digit is generated, the UNet also receives the class \(c\) as a one-hot vector. Two more FCBlocks embed it: the class embedding scales the features and the time embedding shifts them.

\[\mathrm{unflatten} \leftarrow c_1 \odot \mathrm{unflatten} + t_1, \qquad \mathrm{up}_1 \leftarrow c_2 \odot \mathrm{up}_1 + t_2\]

During training the one-hot vector is replaced by zeros with probability \(p_{\mathrm{uncond}} = 0.1\), so the same network also learns an unconditional velocity, which classifier-free guidance needs at sampling time. A zero vector still passes through the FCBlock biases, so "no class" gets its own learned embedding.

ClassConditionalUNet.forward

def forward(
    self,
    x: torch.Tensor,
    c: torch.Tensor,
    t: torch.Tensor,
    mask: Optional[torch.Tensor] = None,
) -> torch.Tensor:
    assert x.shape[-2:] == (28, 28), "Expect input shape to be (28, 28)."
    t = t.float()
    c = F.one_hot(c, self.num_classes).float()
    if mask is not None:
        c = c*mask[:, None]
    x1 = self.conv1(x)
    x2 = self.down1(x1)
    x3 = self.down2(x2)

    t1 = self.fc1(t[:, None])[:,:,None,None]
    t2 = self.fc2(t[:, None])[:,:,None,None]
    c1 = self.fc1_c(c)[:,:,None,None]
    c2 = self.fc2_c(c)[:,:,None,None]

    y0 = c1*self.unflatten(self.flatten(x3)) + t1
    y1 = c2*self.up1(torch.cat([x3, y0], dim=1)) + t2
    y2 = self.up2(torch.cat([x2, y1], dim=1))
    y3 = self.conv2(torch.cat([x1, y2], dim=1))
    return self.conv3(y3)

2.5 Training the Class-Conditioned UNet

class_fm_forward

def class_fm_forward(
    unet: ClassConditionalUNet,
    x_1: torch.Tensor,
    c: torch.Tensor,
    p_uncond: float,
    num_ts: int,
) -> torch.Tensor:
    unet.train()
    N = x_1.shape[0]
    mask = (torch.rand(N, device=x_1.device) >= p_uncond).float()
    t = torch.rand(N, device=x_1.device)
    x_0 = torch.randn_like(x_1)
    t_b = t[:, None, None, None]
    x_t = (1 - t_b) * x_0 + t_b * x_1
    return F.mse_loss(unet(x_t, c, t, mask), x_1 - x_0)

Part 2: Training a Flow Matching Model

2.6 Sampling with Classifier-Free Guidance

\[u = u_\theta(x_t, t, \varnothing) + \gamma\,\big(u_\theta(x_t, t, c) - u_\theta(x_t, t, \varnothing)\big)\]

class_fm_sample

@torch.inference_mode()
def class_fm_sample(
    unet: ClassConditionalUNet,
    c: torch.Tensor,
    img_wh: tuple[int, int],
    num_ts: int,
    guidance_scale: float = 5.0,
    seed: int = 0,
) -> torch.Tensor:
    unet.eval()
    device = next(unet.parameters()).device
    c = c.to(device)
    N = c.shape[0]
    g = torch.Generator().manual_seed(seed)
    x = torch.randn(N, unet.conv3.out_channels, *img_wh, generator=g).to(device)
    for i in range(num_ts):
        t = torch.full((N,), i / num_ts, device=device)
        u_uncond = unet(x, c, t, torch.zeros(N, device=device))
        u_cond = unet(x, c, t, torch.ones(N, device=device))
        u = u_uncond + guidance_scale * (u_cond - u_uncond)
        x = x + u / num_ts
    return x

2.6 Removing the Learning-Rate Scheduler

The exponential schedule starts at \(10^{-2}\) and ends at \(10^{-3}\). Simply deleting it would keep the step size at \(10^{-2}\) to the end of training. Instead I trained an identical, independent model with a constant learning rate of \(10^{-3}\), the schedule’s final value.

What I changed

I removed ExponentialLR and its per-epoch scheduler.step(), and set Adam’s learning rate to a constant \(10^{-3}\). Everything else matches Section 2.5: architecture, batch size, class dropout, epochs, and sampling.

Why it compensates

The scheduler’s job is to shrink the step size late in training so the weights settle. A constant small learning rate gives that stability from the first step, and Adam’s per-parameter adaptive steps keep early progress reasonable. The cost is smaller steps early in training, when larger ones are safe; in this run that did not slow progress.

Without the large initial learning rate the early spike disappears: the first steps peak near 1.2 instead of about 4, and both runs flatten out near 0.1.

At epochs 5 and 10 the two runs are hard to tell apart: both give well-formed digits with varied slant and stroke width, with only small artifacts such as a stray dot beside a 1.
