Part A: Image Warping and Mosaicing

Photographs taken by rotating a camera about a fixed center of projection are related by homographies. I recover each homography from hand-picked correspondences, write inverse warping with nearest neighbor and bilinear interpolation, rectify planar objects, and blend three-image mosaics with a linear feather.

Part A.2

A.2 Recover Homographies

A homography maps \(p = (x, y, 1)^\top\) to \(p' \sim Hp\). Fixing \(h_{33} = 1\) leaves 8 unknowns. Each correspondence gives two equations, so I click 14–19 pairs per image pair and solve the overdetermined system by least squares.

\[\begin{bmatrix} wx' \\ wy' \\ w \end{bmatrix} = \begin{bmatrix} h_1 & h_2 & h_3 \\ h_4 & h_5 & h_6 \\ h_7 & h_8 & 1 \end{bmatrix}\begin{bmatrix} x \\ y \\ 1 \end{bmatrix} \quad\Rightarrow\quad x' = \frac{h_1x + h_2y + h_3}{h_7x + h_8y + 1},\quad y' = \frac{h_4x + h_5y + h_6}{h_7x + h_8y + 1}\]

Multiplying through by the denominator makes both equations linear in \(h\). Each pair of points adds two rows to \(A h = b\):

\[\begin{bmatrix} x & y & 1 & 0 & 0 & 0 & -x x' & -y x' \\ 0 & 0 & 0 & x & y & 1 & -x y' & -y y' \\ & & & & \vdots & & & \end{bmatrix}\begin{bmatrix} h_1 \\ \vdots \\ h_8 \end{bmatrix} = \begin{bmatrix} x' \\ y' \\ \vdots \end{bmatrix}, \qquad h = (A^\top A)^{-1}A^\top b\]

computeH

def computeH(img1_pts, img2_pts):
    A = []
    b = []
    for (x1, y1), (x2, y2) in zip(img1_pts, img2_pts):
        A.append([-x1, -y1, -1, 0, 0, 0, x2*x1, x2*y1])
        A.append([0, 0, 0, -x1, -y1, -1, y2*x1, y2*y1])
        b.append(-x2)
        b.append(-y2)
    A = np.array(A)
    b = np.array(b)
    H = np.linalg.inv(A.T @ A) @ A.T @ b
    H = np.append(H, 1.0)
    return H.reshape(3, 3)

Part A.3

A.3 Warp the Images

I use inverse warping. Forward-mapping each source pixel would leave holes in the output, so I go the other way: map each output pixel back through \(H^{-1}\) and sample the source there. This guarantees every output pixel gets a value.

01

Bounding box

Push the four corners through \(H\), divide by \(w\), and take the floor of the minima and the ceiling of the maxima. This box sets the output size. Its top-left corner \((x_{\min}, y_{\min})\) is returned so the mosaic code knows where to place the result.

02

Inverse map

Build homogeneous coordinates for every output pixel with meshgrid, multiply all of them by \(H^{-1}\) at once, and divide by the third row. This gives a sub-pixel source location \((s_x, s_y)\) for every output pixel.

03

Sample

Nearest neighbor: round \((s_x, s_y)\) and copy that pixel. Bilinear: blend the four surrounding pixels. Locations that fall outside the source get \(\alpha = 0\), which marks them as having no data.

\[I'(x, y) = (1-d_y)\big[(1-d_x)\,I_{00} + d_x\,I_{10}\big] + d_y\big[(1-d_x)\,I_{01} + d_x\,I_{11}\big],\qquad d_x = s_x - \lfloor s_x\rfloor,\; d_y = s_y - \lfloor s_y\rfloor\]

inverse_map, warpImageNearestNeighbor, warpImageBilinear

def inverse_map(im, H):
    x_min, y_min, x_max, y_max = warp_bounds(im.shape, H)
    out_w = x_max - x_min + 1
    out_h = y_max - y_min + 1
    xs, ys = np.meshgrid(np.arange(x_min, x_max + 1), np.arange(y_min, y_max + 1))
    pts = np.array([xs.flatten(), ys.flatten(), np.ones(out_w * out_h)])
    src = np.linalg.inv(H) @ pts
    sx = (src[0] / src[2]).reshape(out_h, out_w)
    sy = (src[1] / src[2]).reshape(out_h, out_w)
    return sx, sy, x_min, y_min, out_w, out_h

def warpImageNearestNeighbor(im, H):
    h, w = im.shape[0], im.shape[1]
    sx, sy, x_min, y_min, out_w, out_h = inverse_map(im, H)
    sx = np.round(sx).astype(int)
    sy = np.round(sy).astype(int)
    inside = (sx >= 0) & (sx < w) & (sy >= 0) & (sy < h)
    imwarped = np.zeros((out_h, out_w, 3), dtype=np.uint8)
    imwarped[inside] = im[sy[inside], sx[inside]]
    alpha = inside.astype(float)
    return imwarped, alpha, (x_min, y_min)

def warpImageBilinear(im, H):
    h, w = im.shape[0], im.shape[1]
    sx, sy, x_min, y_min, out_w, out_h = inverse_map(im, H)
    inside = (sx >= 0) & (sx <= w - 1) & (sy >= 0) & (sy <= h - 1)
    sx = sx[inside]
    sy = sy[inside]
    x0 = np.minimum(np.floor(sx).astype(int), w - 2)   # keep x0 + 1 inside the image
    y0 = np.minimum(np.floor(sy).astype(int), h - 2)
    dx = (sx - x0).reshape(-1, 1)
    dy = (sy - y0).reshape(-1, 1)
    img = im.astype(float)
    top = img[y0, x0] * (1 - dx) + img[y0, x0 + 1] * dx
    bottom = img[y0 + 1, x0] * (1 - dx) + img[y0 + 1, x0 + 1] * dx
    values = top * (1 - dy) + bottom * dy
    imwarped = np.zeros((out_h, out_w, 3), dtype=np.uint8)
    imwarped[inside] = np.clip(np.round(values), 0, 255).astype(np.uint8)
    alpha = inside.astype(float)
    return imwarped, alpha, (x_min, y_min)

Part A.3

A.3 Nearest Neighbor vs Bilinear

Both methods compute the same inverse map; they differ only in how they read the source. Nearest neighbor reads one pixel per output pixel. Bilinear reads four and computes a weighted sum.

Quality

Nearest neighbor copies whole source pixels, so slanted strokes and box edges turn into stair steps and letters look blocky. Bilinear interpolation turns those steps into smooth ramps, at the cost of slight blur: it never produces a value sharper than its four neighbors.

Part A.4

A.4 Blend the Images into a Mosaic

The middle photo of each set is the reference and is left unwarped. The left photo is warped by \(H_{\text{left}\to\text{mid}}\), and the right photo by \(H_{\text{mid}\to\text{right}}^{-1}\). My own photos are reduced to 1/4 size first, and their homographies are rescaled to match.

01

Rescale H

The points were clicked at full resolution. Reducing every image by a factor \(s\) changes the homography to \(S H S^{-1}\) with \(S = \operatorname{diag}(s, s, 1)\), so I never re-click points.

02

Warp and weight

Each image is warped with warpImageBilinear. Its weight is a linear feather defined in the source image: 1 at the center, falling to 0 at every edge. I evaluate the weight at the same back-projected location \((s_x, s_y)\) that inverse_map returns, so it lines up exactly with the warped pixels. Then I multiply by \(\alpha\).

03

Canvas and weighted average

The canvas spans the union of all warped bounding boxes. Each image is accumulated at offset \((x_{\min} - \text{left},\, y_{\min} - \text{top})\). Inside the overlap, the weights hand each pixel off gradually from one photo to the next, so no hard seam appears.

\[w(s_x, s_y) = \Big(1 - \big|\tfrac{2s_x}{W-1} - 1\big|\Big)\Big(1 - \big|\tfrac{2s_y}{H-1} - 1\big|\Big),\qquad I_{\text{mosaic}} = \frac{\sum_i w_i\,\alpha_i\,I_i}{\sum_i w_i\,\alpha_i}\]

feather_weight, mosaic

def feather_weight(im, H):
    h, w = im.shape[0], im.shape[1]
    sx, sy, _, _, _, _ = inverse_map(im, H)
    wx = 1 - np.abs(2 * sx / (w - 1) - 1)
    wy = 1 - np.abs(2 * sy / (h - 1) - 1)
    return np.clip(wx * wy, 0, 1)

def mosaic(names, Hs, scale):
    S = np.diag([scale, scale, 1])
    parts = []
    for name, H in zip(names, Hs):
        im = load_small(name, scale)
        H = S @ H @ np.linalg.inv(S)
        imwarped, alpha, (x_min, y_min) = warpImageBilinear(im, H)
        weight = feather_weight(im, H) * alpha
        parts.append((imwarped, weight, x_min, y_min))

    left = min(p[2] for p in parts)
    top = min(p[3] for p in parts)
    right = max(p[2] + p[0].shape[1] for p in parts)
    bottom = max(p[3] + p[0].shape[0] for p in parts)

    total = np.zeros((bottom - top, right - left, 3))
    total_weight = np.zeros((bottom - top, right - left))
    for imwarped, weight, x_min, y_min in parts:
        r, c = y_min - top, x_min - left
        h, w = weight.shape
        total[r:r + h, c:c + w] += imwarped * weight[:, :, None]
        total_weight[r:r + h, c:c + w] += weight

    total_weight[total_weight == 0] = 1
    result = total / total_weight[:, :, None]
    return result.astype(np.uint8)
